**What broke:**
- The trace demo's seed-parser regex initially only matched `[A-Z]+-\d+` ids,
  so `EXT-C01`-style ids (letters then digits after the hyphen) never loaded —
  the graph came up as 31 locations / 64 roads and Dijkstra threw
  "Unknown source node". Fixed the pattern to `[A-Z]+-[A-Z]*\d+`; graph now
  loads 50 locations / 98 roads.

**Decided:**
- Flood-prone threshold = roadConditionWeight ≥ 1.5 (the seed data's weights
  are 1.0–3.0; 1.6/1.8/2.0/2.5/3.0 count, 1.0–1.4 don't). Documented in Config
  and the report. Easy for the examiner to live-edit.
- `decreaseKey` uses a linear scan rather than an indexed heap. At this
  dataset's size the O(n) locate is fine, and it keeps the heap free of the
  index-map bookkeeping; flagged in the report for the efficiency lab to
  measure.

- Flag for C4/A1: the graph API rejects parallel edges, so the seeded flood-
